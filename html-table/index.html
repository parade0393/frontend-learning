关于 HTML Table

HTML 表格不仅仅是展示数据的结构，更是可访问性与语义化的关键。 本模块将以细颗粒度拆解 table 的所有核心用法，覆盖结构、分区、表头关联、合并、布局与响应式。

  • 结构元素 - table、tr、td、caption 的基础构成
  • 语义分区 - thead、tbody、tfoot 的组织方式
  • 表头关联 - th、scope、headers 让表格可读可访问
  • 列与合并 - colgroup/col 与 rowspan/colspan 控制结构
