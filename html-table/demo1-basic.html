基础结构

掌握 table、tr、td 的核心骨架

概念说明

HTML 表格由 table 作为容器，内部由行 tr 组成，每行包含多个单元格 td。 这是所有表格结构的起点。

常见坑：浏览器会自动补全缺失的 tbody，因此用脚本选择行时要注意实际 DOM 结构。 同时不要用 table 做纯布局，表格应当用于数据展示；表头请使用 th 而不是用样式伪装。

  • table：表格容器
  • tr：表格行
  • td：数据单元格

基础语法

<table>
  <tr>
    <td>产品</td>
    <td>价格</td>
    <td>库存</td>
  </tr>
  <tr>
    <td>键盘</td>
    <td>299</td>
    <td>120</td>
  </tr>
</table>
